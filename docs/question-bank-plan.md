# Question Bank — plan

Status: **planned 2026-10-13, owner's answers recorded; not started.** Progress goes in
`CLAUDE.md` → Feature status.

A shared bank of past exam MCQs that every user can browse and practise, and only the super admin
uploads (thousands of rows, from the owner's Google Sheet / Excel).

## 2. The owner's sheet

Columns, in order: `#`, `ID`, `বিষয় (Category)`, `উপ-বিষয় (Subcategory)`, `ক্রম (Serial)`,
`প্রশ্ন (Question)`, `ক`, `খ`, `গ`, `ঘ`, `সঠিক উত্তর (Letter)`, `সঠিক উত্তর (Answer)`, `BCS Source`.

Seen in the data: the sub-category and the source are sometimes empty; the answer letter is a
Bangla letter (ক–ঘ); the source is text like `৪৪তম বিসিএস`.

## 3. Data model (shared, like vocabulary — no per-user copies)

- `BankExam` enum: `BCS`, `PRIMARY`, `GRADE_11_20`.
- `BankQuestion`
  - `exam`, `sourceId` (the sheet's `ID`) — **`@@unique([exam, sourceId])`**: re-uploading a file
    updates rows instead of duplicating them, so fixing the sheet and uploading again fixes the bank.
  - `subject` (বিষয়), `subtopic?` (উপ-বিষয়; empty shows as "অন্যান্য"), `serial?`.
  - `text`, `options String[]` (always 4, ক খ গ ঘ), `correctIndex` (0–3).
  - `source?` (e.g. `৪৪তম বিসিএস`), `explanation?`, `explanationByAi Boolean`.
  - `uploadId?` → `BankUpload`, timestamps.
  - Index `[exam, subject, subtopic, serial]`.
  - Subjects are plain strings taken from the sheet (no subject table): the lists come from a
    `groupBy`, and renaming a subject means fixing the sheet and re-uploading.
- `BankUpload`: `exam`, `fileName`, `created`, `updated`, `uploadedById`, `createdAt` — the
  history, and the handle for "undo this upload" (deletes only the rows it **created**).
- `BankAttempt` (per user): `userId`, `exam`, `subject?`, `subtopic?`, `questionIds`, `total`,
  `correct`, `details Json`, `startedAt`, `submittedAt?`.
- Later (phase 4): `BankMark` (per user: bookmarked / answered wrong).

The migration is additive (new tables and an enum only), hand-written and idempotent; ask the owner
before applying it.

## 4. Pages

- `/question-bank` with three tabs (`?exam=bcs|primary|grade`), in the nav and the "More" sheet.
- Tab → subjects (with question counts) → sub-topics → question list.
  - The list is paged on the server (~30 per page); never send thousands of rows to the page.
  - Each question: options, "উত্তর দেখাও" reveals the answer and the explanation, the source badge.
  - Filters: sub-topic, source (sorted by the number in `৪৪তম`, Bangla digits), text search
    (`ILIKE` is fine for thousands; add a trigram index only if it gets slow).
- Exam from the bank: pick subject / sub-topic / sources and a count → random questions → timed
  test → result. **Answers never reach the page during the test**: the server stores the chosen
  `questionIds` in a `BankAttempt` at start and grades on submit (same rule as Preliminary TESTING).
- "Copy to my Preliminary set": selected questions become a normal `QuestionSet` of the user (a
  copy; the bank is untouched).
- Super admin only: ✏️ edit a question in place, and the upload page below.
- Voice: add `question_bank` to `assistantPages`, the quick commands and the AI prompt.

## 5. Upload (super admin) — `/admin/question-bank/upload`

1. Choose the tab (exam) and a file: **.xlsx** (Google Sheets → File → Download → Microsoft Excel)
   or **.csv**. For a workbook, choose the sheet.
2. The file is read **in the browser** (nothing is sent yet). Columns are mapped automatically by
   header name; the admin can correct the mapping with dropdowns.
3. Preview and validation, per row:
   - question or any option empty; answer letter not ক/খ/গ/ঘ (also accept a–d / 1–4);
   - the answer text column doesn't match the option the letter points to (a common sheet error);
   - the same `ID` twice in the file;
   - counts: total, OK, **new**, **will update**, with errors listed by row and downloadable as CSV.
4. Upload the valid rows in **batches of ~500** (Vercel body size and time limits), with a
   progress bar. Each batch is an upsert on `(exam, sourceId)`, so a stopped upload can simply be
   run again.
5. A `BankUpload` row records the result; "undo" deletes the rows that upload created.

Parsing library: decide when building — SheetJS from its own CDN tarball (the npm `xlsx` package
is outdated) or `exceljs` for .xlsx, `papaparse` for CSV. **Stop `pnpm dev` before `pnpm add`.**

## 6. Math "as in a textbook"

The app already renders `$…$` with KaTeX (`MathText`) and `<u>…</u>` as underline. The sheet
probably has plain text math (`x²`, `১/২`, `√3`), which shows flat. So:

- The upload preview **flags rows that look mathematical** (digits with `/ ^ √ ² ³ π ∠ ≤ ≥`, etc.)
  and shows each question rendered as users will see it.
- Super admin action **"AI দিয়ে math ঠিক করো"** on the flagged rows: the AI rewrites only the math
  into LaTeX (`$\frac{1}{2}$`, `$\sqrt{3}$`, `$x^{2}$`) and changes no other word; the admin
  reviews the rendered result before saving. The same fix is available when editing one question.
- If the owner writes `$…$` in the sheet directly, it is used as is.

## 7. AI explanations

- Super admin: "AI দিয়ে ব্যাখ্যা" on one question, or for a whole subject / sub-topic in the
  background, in groups of ~20 questions per AI call, skipping questions that already have one.
- Stored in `explanation` with `explanationByAi = true`; users see an "AI-লিখিত" label; the admin
  can edit it (then the flag clears).
- Uses `callAI` (`src/server/assistant/ai.ts`); usage is recorded in `AiUsage` like other AI
  features. An explanation in the sheet is never overwritten by AI.
